# SecondLook

**Does the repair photo actually show the fix?** Before a ward supervisor closes a streetlight complaint, SecondLook compares the complaint with the repair photo. It either asks for a better photo or hands the case to the supervisor. The AI never closes a case.

IDEA//FORGE · Track 1: Civic Pulse

## Try it

Open the [live site](https://thanujgthub.github.io/secondlook/), choose **Demo script**, and start the five-step walkthrough.

1. **Day photo.** The Gate 2 pole in daylight. SecondLook asks for an after-dark photo with the lamp on.
2. **Night photo.** The lit Gate 2 lamp. Ready for human review, and the supervisor can accept it.
3. **Whole row.** Same photo, but the complaint now covers the whole row. SecondLook asks for a wider view.
4. **Two dark lamps.** The wider photo shows two lights still dark. SecondLook flags an incomplete repair.
5. **Full repair.** All five lights are on. The case is ready for supervisor sign-off.

**Demo mode** uses sample cases and needs no key. **Live mode** sends the selected photo and complaint to Gemini or Claude. Add that provider's API key in AI settings. Keys are stored separately for the current browser tab and only sent to the provider they belong to. Gemini results display the model version returned by Google when available. Supervisor actions are practice decisions recorded in the current session.

The sample photos are illustrations generated by `scripts/make_samples.py`.

## Run locally

```sh
python -m http.server 8000   # then open http://localhost:8000
node scripts/test-review.mjs # review-logic tests
```

No build step and no dependencies: `index.html`, `css/styles.css`, `js/app.js` (UI), `js/review.js` (AI review), `js/data.js` (samples and demo results).

## Why

In Gurugram, a resident who reported broken streetlights said officials uploaded a daytime photo of the poles, leaving him unable to tell whether the lights worked at night. [Hindustan Times interview](https://www.hindustantimes.com/cities/gurugram-news/mcgs-24-hour-grievance-redressal-portal-faces-flak-over-delays-incomplete-fixes-101793211559872.html)
