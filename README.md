# SecondLook

**Does the repair photo actually show the fix?** Before a ward supervisor closes a streetlight complaint, SecondLook compares the complaint with the repair photo. It either asks for a better photo or hands the case to the supervisor. The AI never closes a case.

IDEA//FORGE · Track 1: Civic Pulse

## Try it

Open the live site and click the three guided steps:

1. **Day photo.** The Gate 2 pole in daylight. SecondLook asks for an after-dark photo with the lamp on.
2. **Night photo.** The lit Gate 2 lamp. Ready for human review, and the supervisor can accept it.
3. **Whole row.** Same photo, but the complaint now covers the whole row. SecondLook asks for a wider view.

**Demo mode** needs no key and covers the sample photos with the preset complaints. **Live mode** sends your own photo and complaint to Claude (`claude-haiku-5-5`) or Gemini (`gemini-3.8-flash`) using an API key you paste in. The key stays in this browser tab (sessionStorage) and goes only to the provider you pick.

The sample photos are illustrations generated by `scripts/make_samples.py`.

## Run locally

```sh
python -m http.server 8000   # then open http://localhost:8000
node scripts/test-review.mjs # review-logic tests
```

No build step and no dependencies: `index.html`, `css/styles.css`, `js/app.js` (UI), `js/review.js` (AI review), `js/data.js` (samples and demo results).

## Why

In Gurugram, a resident reported broken streetlights, and the case was closed with a daytime photo of the poles ([Hindustan Times](https://www.hindustantimes.com/cities/gurugram-news/mcgs-24-hour-grievance-redressal-portal-faces-flak-over-delays-incomplete-fixes-101793211559872.html)). A daytime photo cannot show whether a lamp works at night. See [SecondLook-Plan.md](SecondLook-Plan.md) for the full plan.
